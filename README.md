# Crusaders Wrestling Foundation website

A responsive, buildless static website using McDevitt navy (#0C233F) and Vegas gold (#A39260).

## Temporary GitHub Pages hosting

Create a separate repository named `cwf-website` under `dane789`. Place `index.html` at the repository root. In Settings → Pages, select Deploy from a branch, main, and / (root). GitHub will return the published URL when deployment completes. No custom domain is configured.
